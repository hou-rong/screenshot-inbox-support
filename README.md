## 开始使用

1. 打开 App，点击「开始扫描」，按意愿授权完整或部分照片访问。
2. 设定每日目标，点击「开始处理」。可以右滑保留、左滑删除、下滑稍后，也可使用页面按钮。
3. 在首页底部查看最近 13 周的处理热力图和每组处理时间、数量。
4. 需要时，在设置中开启本地提醒，或添加桌面小组件。

## 常见问题

### 为什么没有找到全部截图？

App 只查询系统标记为截图的图片。部分照片权限下，只能处理已授权范围，可以在 App 或系统设置中添加更多照片。尚未下载到本机的 iCloud 图片，请先在系统「照片」中下载。

### 保留会移动图片吗？

不会。保留只在本地标记已处理，原图位置不变。稍后不计入完成量，图片会在到期后重新出现。

### 删除后如何恢复？

删除由系统照片图库执行。请在系统「照片」的「最近删除」中查看；保留期限和恢复方式由系统管理。

### 如何清除处理历史？

在设置中选择清除已处理数据，会清除本地状态、统计和暂停进度，保留偏好设置。该操作不会删除系统照片，也不会恢复已删除的图片。

### 热力图和明细如何计数？

保留和成功删除计入处理量，稍后单独显示。每日统计按本地日期计算，暂停后继续仍属于同一组。旧版本未保存批次边界的历史明确显示为按日汇总。

### Widget 为什么不是实时数量？

Widget 显示最后同步的数量和时间。系统图库变化后，打开 App 刷新可同步；后台刷新时机由 iOS 控制。
